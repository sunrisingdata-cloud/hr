# 엑셀 업로드 양식

근태관리·휴가관리 화면의 **엑셀 업로드**에 쓰는 양식이다. `.csv`(UTF-8 BOM)로 제공하며,
엑셀에서 열어 편집한 뒤 `.xlsx`로 저장해 올려도 된다.

## 공통 규칙

- **첫 행이 헤더**다. 헤더 이름으로 열을 찾으므로 열 순서는 바뀌어도 된다.
- `직원ID`, `연월일` 은 필수. 이름이 비면 호봉관리(없으면 직원명부)에서 자동으로 채운다.
- 같은 `직원ID` + `연월일` 행이 이미 있으면 **덮어쓴다**(재업로드로 수정 가능).
- 시간은 `HH:MM`(예: `09:00`), 날짜는 `YYYY-MM-DD`.

## 파일별

| 파일 | 시트 | 헤더 |
|---|---|---|
| `근태기록_양식.csv` | 근태기록 | 직원ID · 이름 · 연월일 · 출근시간 · 퇴근시간 |
| `시간외근로_양식.csv` | 시간외근로 | 직원ID · 이름 · 연월일 · 시작시간 · 종료시간 · 비고 |
| `휴가기록_양식.csv` | 휴가기록 | 직원ID · 이름 · 연월일 · 휴가종류 · 사용시간 |

- **사용시간**: 종일 `8`, 반차 `4`, 그 외 실제 시간 수. 비우면 종일(8)로 간주.
- **휴가종류**: 잔여 계산 대상은 `연차휴가`·`대체휴무`·`개관기념일`·`건강검진휴가`·`가족돌봄휴가`·`가족기념일`·`기타`.
  종류 이름에 `무급` 이 들어가면 월급 계산에서 무급일수로 집계된다.
